# 고래영어 홈페이지 - 브리프

> 초중등 영어 학원을 찾는 학부모가 고래영어의 교육 철학과 맞춤 관리 방식을 이해하고 전화나 카카오톡으로 상담할 수 있는 정적 소개 홈페이지

## 문제와 타겟

- **타겟**: 초등부터 중등까지 자녀의 영어 학원을 찾는 학부모
- **문제**: 여러 홍보 채널만으로는 고래영어의 교육 철학, 수업 방식, 실제 관리 수준을 한눈에 파악하기 어려움
- **현재의 대안**: 지인 소개, 맘카페, 전단지, 네이버 검색, X, 네이버 쇼츠를 통해 학원을 접하고 개별적으로 정보를 확인

## 핵심 가치

- **한 문장 가치 제안**: 학생의 가능성을 끝까지 믿고, 스스로 공부할 수 있도록 끈질기게 돕는 영어 학원
- **결정적 차별점**: 학생마다 부족한 지점을 찾아 채우는 일대일 맞춤 관리로 초등 시기에 자기주도 학습의 기반을 형성
- **핵심 메시지**: 기본은 탄탄하게, 공부는 스스로, 실력은 오래가게

## 도메인 역학

- **콜드스타트**: 원장 소개, 교육 철학, 후기 5개, 교실과 수업 사진, 네이버 블로그 콘텐츠를 기존 자료로 채움
- **획득 경로**: Vercel 공개 링크를 기존 홍보 채널에서 공유
- **재방문 동기**: 첫 버전에서는 중요하지 않음. 한 번의 방문으로 신뢰 형성과 상담 연결에 집중
- **수익**: 홈페이지 내 결제는 제외하고 오프라인 상담과 등록으로 연결

## 범위와 성공 기준

- **플랫폼**: 모바일과 데스크톱에 대응하는 반응형 웹
- **배포**: GitHub 저장소를 Vercel에 연결
- **기간**: 기획 확정 후 바로 제작
- **절대 안 빼는 것**: 교육 철학, 맞춤 관리 방식, 후기와 사진, 전화와 카카오톡 문의
- **이번에 안 하는 것**: 회원가입, 게시판, 관리자 화면, 온라인 결제, 콘텐츠 관리
- **성공 기준**: Vercel 공개 주소에서 모바일과 데스크톱 화면이 정상적으로 보이고 전화와 카카오톡 문의가 작동하는 상태
