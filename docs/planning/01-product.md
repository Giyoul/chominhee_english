# 고래영어 홈페이지 - 프로덕트 정의

> 이 문서는 한 페이지형 홈페이지의 정보 구조와 사용자 흐름을 정의한다.

## 핵심 사용자 여정

```text
공유 링크 접속
→ 교육 철학 이해
→ 맞춤 수업 방식 확인
→ 후기와 실제 사진 확인
→ 원장 경력 확인
→ 전화 또는 카카오톡 문의
```

첫 방문자가 한 페이지 안에서 고래영어의 방향과 신뢰 근거를 확인하도록 구성한다. 이미 학원을 알고 방문한 사용자는 첫 화면이나 고정 상담 영역에서 바로 문의할 수 있다.

## 화면 목록

### 한 페이지형 학원 소개

- **목적**: 고래영어의 교육 방식에 대한 신뢰를 만들고 상담으로 연결
- **유입**: Vercel 링크를 공유한 지인, 맘카페, 전단지, 검색, X, 네이버 쇼츠
- **이동**: 페이지 내부 영역 이동, 전화 연결, 카카오톡 문의, 네이버 블로그

#### 상단 안내

- 학원명
- 교육 철학, 수업 안내, 후기, 원장 소개로 이동하는 메뉴
- 전화 상담
- 모바일용 간결한 메뉴

#### 첫 화면

- `기본은 탄탄하게, 공부는 스스로, 실력은 오래가게`
- `초등 때 만든 공부의 힘이 중학교에서도 이어지도록`
- 일대일 맞춤 영어 수업에 대한 짧은 설명
- 전화 상담과 카카오톡 문의
- 원장 또는 실제 수업 대표 이미지

#### 학부모의 고민

- 단어를 외워도 문장을 읽지 못하는 문제
- 문법을 배워도 문장 속에서 찾지 못하는 문제
- 숙제는 하지만 혼자 공부하는 습관이 형성되지 않은 문제
- 진도보다 배운 내용을 자기 것으로 만드는 과정이 중요하다는 설명

#### 교육 방식

```text
품사 → 문장 구조 → 문법 → 독해
```

- 단어의 역할 이해
- 문장이 만들어지는 원리 파악
- 문법을 실제 문장에서 발견
- 배운 내용을 이용해 스스로 읽고 설명
- 학생마다 막히는 지점을 개별적으로 확인하고 보완

#### 교육 과정

- **초등 고래영어**: 파닉스, 리딩, 문장 구조, 어휘, 문법, 독해, 공부 습관
- **중등 조민희영어**: 학교별 내신 관리, 문법, 독해, 서술형, 고등 영어 기반
- 초등에서 만든 공부의 힘을 중등 실력으로 연결한다는 설명

#### 실제 수업 모습

- 교실 사진
- 학생별 교재로 학습하는 수업 사진
- 사진 공개 동의를 받지 못한 학생은 얼굴 가림 처리

#### 학부모 후기

- 후기 5개의 핵심 내용을 읽기 쉬운 형태로 제공
- 맞춤 지도, 체계적인 수업, 꾸준한 관리, 선생님의 열정과 소통을 중심으로 구성
- 실제 후기임을 확인할 수 있도록 원문 캡처 제공

#### 성장 이야기와 교재

- 학생 성장 사례 소개
- 교재와 학습 방식 소개
- 자세한 내용은 네이버 블로그로 연결

#### 원장 소개

- 정교사 2급 자격증
- 고등학교 기간제 교사
- 고등학교 입시상담 교사
- 고등 입시 13년
- 영어교육 전공 석사
- 호주 유학
- `입시까지 경험한 원장이 초등 시기의 기본기를 직접 설계합니다`라는 의미로 경력 연결

#### 상담 안내

- `우리 아이는 어디에서 막히고 있을까요?`
- 현재 학습 상태를 함께 살펴보고 필요한 과정을 안내한다는 설명
- 전화 상담
- 카카오톡 문의
- 준비되면 학원 주소와 운영 시간 표시

#### 하단 정보

- 학원명
- 전화번호
- 카카오톡
- 네이버 블로그
- 학원 주소와 필요한 사업자 정보

## 주요 상태

- **정상**: 이미지, 후기, 연락처, 외부 링크 표시
- **이미지 오류**: 오류가 발생한 이미지 영역만 숨기고 텍스트 유지
- **연락처 미정**: 상담 버튼을 숨기고 임시 연락처는 표시하지 않음
- **모바일**: 전화와 카카오톡 문의를 화면 하단에서 계속 접근 가능하게 제공

## 이후 단계 화면

- 공지와 수업 소식 - 고정형 운영이므로 제외
- 상담 신청서 - 전화와 카카오톡 문의만 사용하므로 제외
- 관리자 화면 - 콘텐츠를 정적으로 관리하므로 제외
- 온라인 결제 - 상담 후 등록하는 현재 흐름과 맞지 않아 제외
