# 고래영어 홈페이지 - 로드맵

> 단계 순서는 공유 링크로 처음 방문한 학부모가 신뢰를 형성하고 상담으로 이어지는 흐름에서 도출했다.

## Phase 1 - 콘텐츠와 상담 정보 준비

- **만들 것, 할 것**: 포스터 문구와 원장 경력을 홈페이지용으로 정리하고 후기, 사진, 블로그 링크를 선별한다. 전화번호, 카카오톡 주소, 학원 주소와 운영 시간을 준비하고 학생 사진의 공개 범위를 확인한다.
- **왜 이게 먼저인가**: 고정형 홈페이지에서는 콘텐츠가 핵심 정보이므로 임시 문구 없이 실제 신뢰 근거를 먼저 확보해야 한다.
- **완료 신호**: 사용할 문구, 이미지, 링크, 상담 정보와 사진 공개 범위가 확정된 상태

## Phase 2 - 반응형 소개 홈페이지 제작

- **만들 것, 할 것**: 교육 철학, 수업 방식, 과정, 후기, 사진, 원장 소개와 상담 영역을 한 페이지로 구성하고 모바일과 데스크톱에 대응한다.
- **왜 이게 먼저인가**: 하나의 링크가 여러 홍보 채널에서 공유되므로 접속 환경과 관계없이 교육 방향과 상담 경로를 확인할 수 있어야 한다.
- **완료 신호**: 모바일과 데스크톱에서 전체 정보를 읽을 수 있고 전화와 카카오톡 문의를 사용할 수 있는 상태

## Phase 3 - GitHub와 Vercel 공개

- **만들 것, 할 것**: GitHub 저장소를 Vercel에 연결하고 공개 주소에서 이미지, 외부 링크, 전화와 카카오톡 문의를 확인한다. 검증된 주소를 기존 홍보 채널에 배포한다.
- **왜 이게 먼저인가**: 첫 유입은 공유된 공개 링크에서 발생하므로 실제 주소에서 상담 흐름까지 작동해야 홈페이지가 역할을 수행한다.
- **완료 신호**: Vercel 주소가 공개되고 실제 모바일과 데스크톱에서 정보 확인과 상담 연결이 가능한 상태

## 미룬 것들

- 회원가입과 사용자 계정 - 소개와 상담에 필요하지 않음
- 공지와 게시판 - 콘텐츠를 고정형으로 운영
- 관리자 화면 - 첫 버전의 콘텐츠 변경 빈도가 낮음
- 온라인 결제 - 상담 후 등록 흐름을 유지
- 검색 최적화 확장 - 공유 링크로 먼저 공개한 뒤 필요에 따라 진행
- 방문 통계와 문의 전환 측정 - 첫 공개 범위에서 제외
